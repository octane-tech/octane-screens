# OctaneScreens (شاشات أوكتين)

Installers for OctaneScreens for Windows, the app that streams Octane World to the office TVs.

Download the latest `OctaneScreens-Setup-<n>.exe` from [Releases](https://github.com/octane-tech/octane-screens/releases/latest), run it, and press Next. Once installed, the app finds new versions here by itself: the control page shows «تحديث للإصدار N».

This repo holds only the built installers. The source is in the private `octane-tech/octane-world` repo (`windows/`, `scripts/tv-stream.mjs`), and `windows/installer/release.sh` there publishes each release.
